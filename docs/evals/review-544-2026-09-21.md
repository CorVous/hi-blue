## Judgement calls assessed

**The `archive/README.md` one-line change (`bec6b7d`) — legitimate, correct, and minimal.**

The file is written in the present tense as a *runbook* ("When to run a playtest", "Running a playtest", step-by-step driver commands), not as a historical record — the historical records are the `NNNN-session.md` files it indexes. Line 21 sits in a list of triggers for running a *new* playtest, and it told a future operator to exercise the "cone projector", a file deleted in `24a217b`. Left unfixed, it would send a reader looking for a module that no longer exists. The human's ruling to fix it is correct.

The fix is also appropriately minimal: it changes exactly the two words "cone projector" → "Vista projector", keeps the surrounding list and phrasing intact, and does not touch any dated transcript or the five other assertions in the same file. It does not rewrite history, because the line was never history — it was an instruction. I found no over-reach here.

One honest caveat for the reviewer: the same README contains *other* stale live instructions (phase vocabulary at `:7-9,17,161-162`; a pointer to a non-existent `0003-claude-opus-4-7-playthrough.md`; a `#phase-banner` DOM selector at `:32`). Those predate this PR and are outside #544's stated scope. Fixing line 21 alone leaves the file half-refreshed — defensible for a ticket about the Vista cutover, but worth a follow-up.

**`CONTEXT.md` and the "no version statement" ruling — correct.** The ticket's second clause reads as a joint requirement, but the first clause ("no longer states schema v11… agree with the landed versions") is what is checkable. The PR corrects the single stale token and adds nothing. Both readings are satisfied: `CONTEXT.md` now agrees with the landed versions where it makes a version claim, and it gained no implementation detail. Verified v12 independently rather than accepting the PR's own citation.

**`AGENTS.md` accuracy.** The new pointer text is accurate: the link resolves, the cited merges are real and correctly paired with their PRs, ADR 0015 is genuinely Accepted, and map #535 is genuinely still open. The `14461ab` accuracy stamp is a slight over-precision (the doc could change without that stamp being updated), but it is a common and harmless doc convention here, and the sentence already defers to "the live map #535 and the source" at `vista-implementation.md:15`.
